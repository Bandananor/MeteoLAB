# MeteoLab

Численная лаборатория атмосферы в браузере. Внутри — **StormLab**: идеализированная облакоразрешающая модель
глубокой конвекции, которая считается в реальном времени, с 3D-визуализацией и диагностикой в духе оперативной
синоптики. Задаётся зондирование (профили температуры, влажности и ветра) и поверхность, дальше модель интегрирует
уравнения движения, термодинамики и микрофизики (дождь, лёд, снег, крупа, град) на сетке ~1 км.

**Статус.** Версия 2.6.1: физика без подгонок, проверенная эталонными тестами и калибровкой; в 2.6 — адвекция (среда
меняется за часы), синоптические ситуации с сюжетом и приземный анализ, в 2.5 — холодные и тёплые
фронты с наклоном, контрастом и скоростью, признаки смерчеобразования, время в часах, в 2.4 — зоны среды на
карте (неоднородная среда: гроза крепнет и слабеет, проходя через них), своя область и скорость до ×120, в 2.3 —
молнии из физики облака и экран грозопеленгатора, в 2.2 — гроза в
реальном зондировании (файлы Вайомингского университета, SHARPpy, CM1/WRF, CSV) и редактор годографа, в 2.1 — новый
набор сценариев и радар с двойной поляризацией (что изменилось — [`CHANGELOG.md`](CHANGELOG.md), план дальше — [`roadmap.markdown`](roadmap.markdown)). Всё, что модель пока не
умеет или упрощает, перечислено в разделе [«Известные ограничения»](#известные-ограничения) с замерами.

## Быстрый старт

Онлайн: **https://bandananor.github.io/MeteoLAB/** — главная, симулятор (`simulator/`), инструкция «Как пользоваться»
(`guide/`) и статья «О модели» (`about/`);
выкладывается вручную: Actions → Pages → Run workflow.

Нужны [Node.js](https://nodejs.org/) 20+ и браузер с WebGL 2.

```bash
git clone https://github.com/Bandananor/MeteoLAB.git
cd MeteoLAB
npm install
npm run dev      # приложение: http://localhost:5173
npm test         # тесты расчётного ядра (Node, без браузера)
npm run test:slow  # калибровочный тест Weisman–Klemp (~15 мин)
npm run test:scenarios  # сценарии по 40 мин модели (~1,5 ч)
npm run test:diurnal    # суточный ход (06:00 → первая гроза) и «Заряженное ружьё» (09:00 → прорыв крышки), ~40 мин
npm run test:reference  # эталоны из литературы: Straka, Bryan & Fritsch (~5 мин)
npm run build    # проверка типов и сборка в dist/
npm run bench -- 6 large  # скорость шага на N потоках в Node и отпечаток полей (одинаков при любом N)
```

Медленные тесты удобнее гонять в облаке: workflow `.github/workflows/slow-tests.yml` (GitHub Actions) считает
быстрые тесты, Weisman–Klemp, эталонные случаи, суточный ход, «Заряженное ружьё» и каждый сценарий с термиком отдельной
задачей параллельно, ~20–60 мин. Запускается сам при
изменении `src/core/` в `main` или вручную: вкладка Actions → Tests → Run workflow.

## Постановка модели

### Область и сетка

| | |
|---|---|
| Область | 48 × 36 × 18,9 км, периодическая по горизонтали; по выбору — большая, 96 × 72 км с тем же шагом (в ~4 раза медленнее). Область движется вместе с грозой (см. ниже) |
| Сетка | 40 × 32 × 50 узлов: Δx = 1,2 км, Δy = 1,125 км; по высоте растянутая — 100 м у земли, шаг растёт в геометрической прогрессии: 9 уровней ниже 1 км, ~340 м на 5 км, ~630 м у тропопаузы, ~970 м наверху |
| Границы по вертикали | земля и верх — непроницаемые стенки (w = 0); губка Рэлея выше max(z_тп + 2,5 км, 14 км) |
| Шаг по времени | Δt = 3 с (до 09.10.2026 — 1 с); оседание осадков дробится по числу Куранта |
| Размеры | параметры ядра (`createGrid`); в интерфейсе — «Стандарт» и «Большая» (`SimConfig.domain`) |
| Движение области | преобразование Галилея (`SimConfig.followStorm`, по умолчанию включено): модель считает в системе, движущейся со скоростью грозы — правой ячейки по Банкерсу при сдвиге 0–6 км от 15 м/с, иначе среднего ветра 0–6 км. Ветер модели — относительно области, фоновый — минус скорость области; трение у земли тянет к ветру над землёй; неоднородность поверхности и сумма осадков привязаны к земле, радар — тоже |

### Переменные и базовое состояние

Прогностические поля в узлах сетки: u, v, w; потенциальная температура θ; массовые доли
пара q_v, облачной воды q_c, дождя q_r, облачного льда q_i, снега q_s, крупы q_g и града q_h; индикатор холодного купола.

Базовое состояние горизонтально однородно и задаётся ползунками:
T(z) — кусочно-линейная с градиентами в слоях 0–3, 3–8 км и 8 км–тропопауза и инверсией
выше, плюс необязательный задерживающий слой: на заданной высоте воздух теплеет на заданные
K в слое 300 м, а над ним лишнее тепло сходит на нет за 2 км (крутой градиент приподнятого
перемешанного слоя, EML); относительная влажность — кусочно-линейная по узлам 0; 1,5; 5 км и тропопауза, плюс
необязательный влажный перемешанный слой: до заданной высоты массовая доля пара равна приземной
(как в хорошо перемешанном пограничном слое днём), но не выше насыщения;
ветер — скорость и направление в узлах 0, 3, 6 и 10 км с линейной интерполяцией.
Давление интегрируется гидростатически по этому профилю: dp/dz = −p·g/(R_d·T_v),
p₀ = 1013,25 гПа. Относительная влажность понимается как отношение массовых долей
(r = RH·r_s, соглашение ВМО).

### Динамика

- Неупругое (anelastic) приближение: ∇·(ρ₀(z)**u**) = 0, ρ₀ — плотность гидростатического
  базового состояния (падает примерно в 8 раз к 19 км).
- Плавучесть B = g·[(θ_v − θ_v0)/θ_v0 − q_c − q_r − q_i − q_s − q_g − q_h], θ_v = θ·(1 + 0,61·q_v): вся вода в облаке
  утяжеляет воздух своей массой.
- Сила Кориолиса на f-плоскости, действует на отклонение ветра от фонового
  (фоновый ветер считается геострофическим).
- Подсеточная турбулентность Смагоринского–Лилли: K = (C_s·Δ)²·√max(0, |S|² − N²/Pr), C_s = 0,18
  (ползунок «Субсеточная турбулентность» — множитель), Pr = 1/3; перемешиваются отклонения u, v, w,
  θ, q_v, q_c от фона во всех трёх направлениях (`src/core/turbulence.ts`). Масштаб Δ: по вертикали ∛(dx·dy·dz),
  для горизонтального перемешивания — √(dx·dy) (с 09.10.2026; сетка 1,2 км по горизонтали и 0,1–0,9 км по вертикали).
- Трение у земли — балк-формула: dV/dt = −C_D(|V|V − |V₀|V₀)/(Δz/2) для нижнего узла,
  C_D = (κ/ln(z_ref/z₀))² по шероховатости поверхности (трава 3 см, вода 0,2 мм, город 1 м).
  Сопротивление фонового ветра считается уравновешенным крупномасштабным потоком, фон не дрейфует.
- Холодный купол, фронт порывов и микропорыв — только из динамики: охлаждение испарением, таянием
  и сублимацией, нагрузка осадками, давление. Ручные параметризации (подъём на краю купола, толчок
  вниз в его ядре, радиальный отток микропорыва) убраны 08.10.2026; поле "холодный купол" (cold) —
  только диагностика охлаждения.

### Численные методы

- **Перенос** (по умолчанию с 29.09.2026) — в форме потоков, WENO5 + RK3 (Wicker–Skamarock):
  WENO 5-го порядка для воды и индикатора холодного купола, линейная схема 5-го порядка для
  u, v, w, θ. Каждый узел — свой контрольный объём; потоки массы через грани проходят свою
  точную проекцию (MAC-проекция Белла–Колеллы–Глаза), поэтому схема сохраняет воду сама,
  без поправок. Оседание дождя — поток ρ₀·q_r·V_t через грани, вытекающее через землю — осадки.
  Отрицательные значения, которые WENO оставляет, заполняются без изменения суммы.
  Код: [`src/core/advection.ts`](src/core/advection.ts). Запасной вариант (переключатель
  «Перенос») — полулагранжев с трилинейной интерполяцией, вдвое быстрее, но размывает потоки.
- **Проекция давления** — точная и согласованная. Скорости хранятся в узлах, давление —
  в центрах «двойственных» ячеек между узлами. Дивергенция ячейки D — поток через её
  грани по восьми углам (именно её видит трилинейный перенос), градиент G = −M⁻¹Dᵀ
  (половинный вес узлов на стенках); условие — D(ρ₀**u**) = 0, так что D·ρ₀·G — согласованный
  лапласиан с весом плотности (поправка — градиент p′/ρ₀). Плотность зависит только от z, поэтому он
  диагонализуется двумерным ДПФ по x, y; для каждой волны решается трёхдиагональная
  система по z. Остаточная дивергенция после проекции ~10⁻¹¹ с⁻¹ (предел float32).
  Код: [`src/core/pressure.ts`](src/core/pressure.ts).
- **Фиксатор массы воды** (только для полулагранжева переноса). Он не консервативен
  (без поправки гроза создаёт ~7,5 % воды в час даже на строго бездивергентной скорости).
  После переноса массы q_v, q_c, q_r (вес ρ₀) восстанавливаются (для дождя — за вычетом
  выпавшего на землю), поправка распределяется пропорционально локальному изменению поля.
  В переносе WENO не используется.

### Микрофизика (объёмная, со льдом)

- Насыщающая коррекция за один шаг: Δq = (q − q_s)/(1 + L²·q_s/(c_p·R_v·T²)), два шага
  Ньютона; избыток пара конденсируется, облако в ненасыщенном воздухе испаряется до насыщения.
- Схема Кесслера (как в Klemp & Wilhelmson 1978 и CM1): автоконверсия 0,001·(q_c − 1 г/кг) с⁻¹,
  аккреция 2,2·q_c·q_r^0,875 с⁻¹.
- Скорость падения дождя V_t = 36,34·(0,001·ρ₀q_r)^0,1364·√(ρ₀(0)/ρ₀) м/с на каждом узле;
  дождь уходит в землю, сумма осадков копится по столбцам (мм).
- Испарение дождя по Klemp–Wilhelmson ∝ (1 − q/q_s)·C·(ρ₀q_r)^0,525, не дальше насыщения;
  охлаждение от него пишется и в θ, и в индикатор cold pool.
- **Лёд** (по умолчанию с 29.09.2026; переключатель «Микрофизика»;
  [`src/core/ice.ts`](src/core/ice.ts), [`src/core/graupel.ts`](src/core/graupel.ts)): облачный
  лёд, снег и крупа по Lin, Farley & Orville (1983)
  с насыщающей коррекцией для смеси воды и льда (Tao et al. 1989). Насыщение над льдом,
  доля льда в облаке линейно от 0 при 0 °C до 1 при −40 °C с теплотой плавления, дождь ниже
  −40 °C замерзает сразу; агрегация льда в снег, сбор снегом льда и облачных капель (обзернение),
  рост и сублимация снега, таяние в дождь, которое не охлаждает воздух ниже 0 °C; оседание снега
  (≈1 м/с) — поток через грани. Крупа (≈8 м/с): замерзание переохлаждённого дождя по Бигу,
  превращение обзернённого снега в крупу, сбор крупой капель, дождя, льда и снега, таяние.
  Град (с 08.10.2026, `src/core/hail.ts`) — отдельный класс плотного льда: рождается из крупы при мокром
  росте (крупа собирает переохлаждённой воды больше, чем успевает заморозить), растёт сухо или мокро
  (в мокром росте лишняя вода сбрасывается дождём), тает и сублимирует; при той же массе падает в ~1,35 раза
  быстрее крупы. У земли считаются полоса града и крупнейшие градины (размер, который превышает одна
  градина на 10 м³; при постоянном N₀ это 1–3 см; для гигантского града нужна двухмоментная схема).
  Вес льда, снега, крупы и града входит в плавучесть. Режим
  «Тёплый дождь» оставлен в переключателе.
  Снег на экране по умолчанию — визуализация частиц осадков по высоте уровня 0 °C.

### Поверхность и солнце

Инсоляция — «солнце в зените» × косинус зенитного угла (широта и склонение солнца по дню года
`dayOfYear`, формула Купера; без него — равноденствие, восход 6:00, закат 18:00). Баланс энергии поверхности
`src/core/surface.ts`: поглощённое = длинноволновые потери (90 Вт/м²) + запас в почве/воде +
H + LE. Доля испарения — «мокрая» доля поверхности × доступность влаги (тип поверхности,
влажность почвы). H и LE целиком уходят в два нижних уровня (профиль exp(−z/300 м)):
Δθ = H/(ρc_pΠh), Δq = LE/(ρL_vh). Ночного выхолаживания нет: старт на рассвете задаётся профилем —
ночная инверсия `nightInversion` (у земли на N K холоднее дневного профиля, к 400 м — на N/4, остаточный слой
до крышки — тоже на N/4; пар у земли сохраняется, до 97 % влажности).

**Город** (`city`, ползунок «Город в центре», с 12.10.2026): круг заданного радиуса посреди области, привязанный к
земле, с переходом 1 км; под ним баланс энергии городской поверхности (альбедо 0,16, почти без испарения, треть энергии
в запас), вне его — выбранной. Шероховатость не меняется. Опыты 12.10.2026 (`tests/bench/scout.ts`): на профиле
«Суточного хода» город радиусом 9 км даёт первые грозы на ~30 мин раньше (11:50 против ~12:30), но не над собой — они
растут там, где их запускают случайные пятна прогрева; крышку даже в 0,5 K не пробивает за весь день ни город, ни поле.
Поэтому сценария «остров тепла» нет: город на сетке ~1,2 км — всего несколько столбцов, его тёплый шлейф уносит ветер.

### Диагностика

- Частица поднимается по давлению среды: сухая адиабата (сохранение θ) до LCL, псевдовлажная
  адиабата dT/dp выше, шаг 25 м. Совпадает с MetPy 1.7.1: CAPE ±1,1 %, CIN ±2 Дж/кг.
- Зондирование частицы от поверхности (в приложении: +0,5 K и вовлечение; для тестов есть
  «чистая» частица), CAPE, CIN, LCL, LFC, EL, точка росы, уровень 0 °C.
- Годограф 0–10 км и сдвиг ветра 0–6 км.
- Спиральность восходящего потока UH = ∫ w·ζ dz по слою 2–5 км (по столбцам) — мера силы
  вращения (≥ 200 м²/с² — «вращение» на экране; в 3-км оперативных моделях обычно ~75).
- **Мезоциклон** (с 08.10.2026) — вращается сам восходящий поток: завихренность ζ на 2–5 км,
  усреднённая с весом w по узлам ядра с w > 10 м/с (связные столбцы), ≥ 3·10⁻³ с⁻¹ и держится
  ≥ 10 мин. Сильный поток наклоняет завихренность сдвига в пару вихрей разного знака на своих
  боках — это честная физика, — и в таком среднем пара гасится, а мезоциклон нет. Прежний
  критерий (максимум UH по области ≥ 400 и в 1,5 раза сильнее антициклонического) засчитывал
  такую пару, как только циклонический вихрь ненадолго перевешивал.
- Число восходящих ядер (связные по горизонтали столбцы, где на ~2–6,5 км есть w > 2 м/с с облаком)
  и классификация режима: одиночная ячейка, мультиячейка, наклонённая ячейка,
  суперячейка с мезоциклоном, преобладание оттока.
- **Ячейки** ([`cells.ts`](src/core/cells.ts)): ядро ячейки — связные (8 соседей) столбцы, где на 1,5–10 км
  есть w > 4 м/с в облаке. Ячейка продолжается там, где её ядро, сдвинутое на её собственное движение,
  перекрывает новое; при расщеплении номер остаётся у части с сильнейшим циклоническим вращением
  (правая ячейка), при слиянии — у суперячейки, затем у старшей. Номер даётся ядру, прожившему 2 мин
  (иначе обломки у края грозы, сливающиеся обратно, получают десятки номеров). Показатели ячейки —
  по её «области»: столбцы ближе 10 км к её центру и ближе к ней, чем к другим ячейкам. Стадии:
  кучевая (дождя у земли < 1 мм/ч), зрелая, распад (поток < 0,45 от максимума или нисходящий сильнее
  восходящего); развитие мезоциклона (ядро ячейки вращается, ζ ≥ 3·10⁻³ с⁻¹); суперячейка
  (вращение ядра 10 мин), окклюзия (холодный отток ≥ 2 K под низким вращением и UH < 0,7 максимума),
  новый мезоциклон после окклюзии, вращение ослабло, распад; левая суперячейка (антициклоническая).
  Новая стадия должна продержаться 1 мин.
- **На какой высоте вращается поток** ([`spin.ts`](src/core/spin.ts), с 12.10.2026): словами под графиком
  w·ζ — средний мезоциклон (2–5 км, по вращению ядра), вращение ниже 3 км (UH 0–3 км ≥ 100 м²/с²) и низкий
  мезоциклон (UH 0–1 км ≥ 20 м²/с²). Пороги — по прогонам 45 мин: у суперячеек UH 0–3 км 160–500, 0–1 км 16–43
  (у WK растёт к 45-й мин до 36), у обычных гроз 0–3 км не больше ~50, 0–1 км меньше 10.
- **Двойная поляризация** ([`polarimetry.ts`](src/core/polarimetry.ts), с 12.10.2026, S-диапазон): ZDR, ρhv и
  KDP в каждом узле из масс осадков. Капли: экспоненциальное распределение с N₀ модели (размер следует из массы),
  отношение осей по Brandes et al. (2002), отражаемость сфероида по горизонтали и вертикали ~ r^(−7/3) (Рэлей),
  интеграл по размерам до 8 мм — таблица по наклону распределения; KDP = (180/λ)·10⁻³·C·W·(1 − r̄) (Bringi и
  Chandrasekar 2001). Лёд — типичные собственные значения из литературы (Kumjian 2013): сухие снег / крупа / град ZDR
  0,4 / 0,2 / 0 дБ, ρhv 0,99 / 0,985 / 0,95; тающие (выше 0 °C) 1,5 / 1 / 0,3 дБ и 0,88 / 0,9 / 0,86. Смесь:
  Zh и Zv складываются, ρhv = Σρᵢ√(Zhᵢ Zvᵢ) / √(ΣZh ΣZv) — разные частицы в одном объёме сами снижают ρhv. На
  WK (12.10.2026, `tests/bench/dualpol.ts`): колонна ZDR ≥ 1 дБ до 6,9 км при 0 °C на 4,1 км (над потоком
  34–39 м/с), полоса таяния ρhv ~0,90 (до 0,86), ядро града с дождём у земли ρhv 0,93 и ZDR ~1,5 (дождь в нём по
  Рэлею перевешивает мелкий град), KDP в ливне до 6–7 °/км. На экране — порог эха 10 dBZ.
- **Обнаружение мезоциклона на радаре** ([`mda.ts`](src/core/mda.ts)), по схеме алгоритма MDA (NSSL):
  на каждом из 14 наклонов — сдвиговые отрезки вдоль дальности (скорость растёт по часовой стрелке
  на ≥ 10 м/с, сдвиг ≥ 3·10⁻³ с⁻¹, длина ≤ 10 км); они объединяются в 2D-признаки (≥ 3 соседних
  строба), признаки — в вертикальные столбы (≥ 3 наклона, глубина ≥ 1,5 км). Vrot — половина
  перепада скорости; сила — по номограмме вращательной скорости (слабый ≥ 12,5, умеренный ≥ 18,
  сильный ≥ 23 м/с; ниже — «циркуляция»). Крюк: на 0,5° эхо ≥ 30 dBZ обвивает низкую циркуляцию
  на 180–330°, а вырез (< 20 dBZ) смотрит в сторону притока — вправо от движения грозы.

## Известные ограничения

Замеры — на тестах ядра (`npm test`); пункт плана указан для каждой строки (уровни — по архиву плана 2.0,
[`roadmap-2.0.markdown`](roadmap-2.0.markdown); что впереди — [`roadmap.markdown`](roadmap.markdown)).

| Ограничение | Что даёт сейчас | Пункт плана |
|---|---|---|
| Горизонтальный шаг ~1,2 км | вовлечение, тонкие струи и вихри у земли не разрешены | ур. 3 (WebGPU, шаг ~500 м; вложенная сетка) |
| θ и поля хранятся в float32 | очень медленный нагрев (меньше ~10⁻⁴ K за шаг) округляется систематически; поэтому потоки от поверхности кладутся только в слой до 500 м | ур. 3 (радиация — хранить θ точнее или копить приращения) |
| Периодическая область | гроза больше не выходит за край (область движется с ней), но соседние ячейки по-прежнему «приходят» с другой стороны; большая область 96 × 72 км в ~4 раза медленнее | ур. 3 (WebGPU) |
| Град однопараметрический (постоянный N₀) | размер градин выводится из массы: 1–3 см, гигантского града (5+ см) не бывает; отражаемость града по Рэлею завышена на несколько dBZ | ур. 3 (двухмоментная микрофизика) |
| Точный перенос WENO (по умолчанию) вдвое дороже прежнего (~70 мс на шаг) | на слабом компьютере расчёт медленнее реального времени при большом ускорении | ур. 3 (WebGPU) |
| При слабом сдвиге поток бывал ~0,8–0,9·√(2·CAPE) (в природе ~0,5–0,6). Со стабильными профилями (11.10.2026) на сценариях 0,5–0,6, но на больших CAPE не перепроверено | пульсирующие грозы могут быть сильнее реальных; сценарии держат CAPE 1–3 кДж/кг | ур. 2 (растянутая сетка), ур. 3 (шаг ~500 м) |
| Широкий начальный термик (~8 км) | сухой средний слой почти не ослабляет поток | ур. 3 (инструменты воздействия: размер термика) |
| ZDR, ρhv, KDP — по средним размерам (одномоментная микрофизика) | сортировка капель по размеру (дуга ZDR) почти не видна; ядро града у земли с ZDR ~1,5 вместо ~0 (мелкий град, дождь перевешивает); KDP — только от дождя | «Вычисления и физика» (двухмоментная микрофизика) |
| Нет ночного выхолаживания | суточный ход — от рассвета (ночная инверсия задана профилем) до вечера, ночи нет | ур. 3 (радиация) |
| Нижнего положительного заряда почти нет, нет коронного разряда с земли (2.3) | под облаком сильный отрицательный потенциал, и в суперячейке ~80 % ударов в землю — положительные (+CG); в природе обычно преобладают −CG | молнии: нижний заряд и корона |
| Живое зондирование — среднее по «тихой» части области | гроза, занявшая почти всю область, попадает в среднее (если тихих столбцов < 5 %); истории профилей нет, только график CAPE/CIN | ур. 2 (живое зондирование) |

### Ядро без браузера

```ts
import { AtmosphereModel, createGrid, DT } from './src/core'

const model = new AtmosphereModel(config, createGrid())  // 40 × 32 × 50, растянутая по высоте
for (let s = 0; s < 3600 / DT; s++) { model.step(DT); model.time += DT }  // час модели
console.log(model.rotation.uh, model.diagnostics().updraft, Math.max(...model.precipitation))
```

Модель детерминирована при заданном `config.seed` (и одинакова при любом числе потоков). Шаг с переносом
WENO на сетке по умолчанию — около 70 мс в одном потоке; на нескольких — `npm run bench -- N`.

## Как пользоваться

Камера: ЛКМ — вращение, ПКМ — сдвиг, колесо — масштаб. Двойной клик по земле — тёплый
влажный пузырь. Изменение профилей перезапускает опыт; кнопки «Сценарии» выставляют
готовую погоду. Вкладки над сценой показывают поля (вертикальная скорость, отклонение
температуры, влажность, завихренность, UH, холодный купол) срезами и объёмом; «Потоки» —
частицы по ветру; «Снег и дождь» — частицы осадков. Щелчок по облаку (или по его номеру) выбирает
ячейку: показатели справа относятся к ней, «Вся область» возвращает максимумы по всей области.

**Радар** (кнопка «Радар» или клавиша R): продукты Z, V, SRV, CR, ZDR, RHO (ρhv), KDP и вертикальный разрез RHI (по
нему тоже можно смотреть Z, SRV, ZDR, ρhv и KDP); 14 углов наклона; щелчок переносит радар, Shift + щелчок — разрез через
точку. «Пиксели данных»: как на экране настоящего радара — радиальными ячейками (луч 0,5° как у NEXRAD
super-resolution или 1°, строб 250 м; ячейка показывает значение в своём центре и расширяется с дальностью) или гладкими
квадратами по 125 м. «Сетка»: радиалы через 10, 30 или 45°, кольца дальности через 5, 10 или 25 км, подписи азимутов градусами или
румбами (С, ССВ, СВ…) — выбор запоминается. «Шкала и палитра»: на каждый вид продукта несколько готовых палитр
(классическая, плавная, для дальтоников), «Изменить» открывает редактор (точки «значение → цвет», плавно, ступенью или
пусто; сохраняется копия в браузере), «Импорт .pal» читает файлы палитр радарных программ (строки `Color:`,
`SolidColor:`, `Color4:`, `Product:`, `Units:`, `Scale:`; скорость в узлах переводится в м/с), «Экспорт .pal»
записывает палитру обратно.

Сценарии заданы в [`src/core/scenarios.ts`](src/core/scenarios.ts); в описании под кнопками — их ML CAPE,
CIN, сдвиг и SRH. Набор пересмотрен 12.10.2026 (план 2.1): каждый сценарий показывает своё явление. «Сухой воздух» и
«Жаркий город» (та же летняя гроза при слабом ветре) убраны, «Сдвиг ветра» стал «Многоячейковой грозой», добавлены
«Классическая суперячейка» и «Заряженное ружьё»; старые ссылки открывают тот же опыт (`share.ts`). Поведение — 40 минут
расчёта, облачный прогон 11.10.2026; новые — прогоны 12.10.2026 (`tests/bench/scout.ts`). Поток — максимум w; ветер у
земли — сильнейший над землёй на 100 м; осадки — максимум суммы в точке; мезоциклон — вращение ядра:

| Сценарий | Среда | Поведение |
|---|---|---|
| Летний день | ML CAPE 2,6 кДж/кг, слабый сдвиг; термик 2,5 км | одиночная гроза: поток до 42 м/с, порывы 17 м/с, 3,7 мм; мезоциклона нет |
| Многоячейковая гроза | 2,9 кДж/кг, сдвиг 13 м/с; термик 2,5 км | новые ячейки на оттоке: поток 36 м/с, порывы 16 м/с; пары вихрей без мезоциклона |
| Классическая суперячейка | 3,8 кДж/кг, сдвиг 28 м/с, SRH 0–1 км 190, без крышки; термик 4,2 км | мезоциклон с ~16-й мин держится 54 мин (на большой области — до конца 90-мин прогона), поток 57 м/с, порывы 32 м/с, град до 1,4 см, 28 мм за 90 мин; UH 0–1 км 16–43 |
| Суперячейка WK | формулы Weisman–Klemp; термик 4,2 км | мезоциклон больше 20 мин, поток 52 м/с, 32 мм, расщепление |
| HSLC | 1,3 кДж/кг, SRH 0–1 км 300, сдвиг 35 м/с; термик 4,2 км | низкая мини-суперячейка: поток 22 м/с, мезоциклон 24 мин, 14 мм |
| Микропорыв | «перевёрнутое V», база ~2,8 км; термик 2,5 км | облако до 25 м/с, почти весь дождь испаряется (0,9 мм), порыв у земли 23 м/с |
| Тропическая конвекция | 2,7 кДж/кг до 16 км, влажно; термик 2,5 км | поток 26 м/с, ливень из тёплого дождя, 21 мм; вращения нет |

| Заряженное ружьё | 9:00, крышка 3 K на 1 км (CIN ~150), ~3 кДж/кг под ней; без термика | кучевые с ~12:10, башни до 9–10 км весь день гаснут под крышкой; около 15:00 прорыв: поток 47–63 м/с, вершины 15–16 км, порывы 33 м/с, 24 мм к 16:30 |

Как подбирались новые (12.10.2026). **Суперячейка:** с крышкой 1,5 K или более сухой серединой (35 % вместо 45) холодный
отток (−8 K) подрезал грозу к 35–50-й минуте; узкие термики (2,5 и 3,2 км) сильный сдвиг рвал сразу. **Ружьё:** время
прорыва решает прогрев за день, а не сила крышки: крышки 1–1,5 K с 9:00 сработали не раньше; со старта в 10:00 прорыв
в ~16:20, с 11:00 (тёплый профиль, CIN 55–75) — не до 15:00.

Медленный тест `npm run test:scenarios` (~30 мин) проверяет, что ни один сценарий с термиком не упирается
в ограничитель скорости и что мезоциклон появляется только там, где задуман; `npm run test:diurnal` — время первых кучевых
и грозы «Суточного хода» и прорыв крышки «Заряженного ружья» (после 14:00, поток больше 40 м/с).

  названия и короткое, которое осталось бы одно в ряду, — во всю ширину. Медленные тесты: сценарии с термиком — по 40 мин

  5/10/25 км, подписи азимутов (градусы или румбы, у края экрана) и дальностей (вдоль луча к дальнему углу). Палитры:
  готовые на каждый вид продукта (NWS и зелёный/красный — прежние цвета точь-в-точь, плавные, для дальтоников),
  редактор своих, импорт и экспорт `.pal`, выбор и свои палитры хранятся в браузере (`palettes.ts`). Шкала рисуется

  мезоциклон, вращение ниже 3 км или низкий мезоциклон (пороги UH 0–3 км 100 и 0–1 км 20 м²/с² — по прогонам

- **02.10.2026 — ячейки: номера, стадии, выбор.** Модель находит ячейки (восходящие ядра) и ведёт их
  во времени: номер сохраняется, пока ячейка движется; при расщеплении он остаётся у правой
  (вращающейся) части, при слиянии — у суперячейки или старшей. В «Состоянии конвекции» — список
  ячеек со стадиями; над облаками на 3D-виде — номера. Щелчок по ячейке (на сцене, по номеру или в
  списке) закрепляет за ней показатели — поток, UH, осадки, вершину, холодный купол — и описание:
  стадия, возраст, откуда взялась, куда и как быстро движется; кольцо на земле отмечает её. Если
  ячейка слилась с другой, выбор переходит к той; если распалась — к области целиком. На
  «Суперячейке» (60 мин): кучевая с 7-й минуты, развитие мезоциклона на 16-й, зрелая суперячейка
  на 25-й, окклюзия на 35-й (холодный отток 2,5 K под низким вращением, UH 1500 → 220), распад на
  37-й.
- **02.10.2026 — радар: обнаружение мезоциклона (MDA) и крюка.** На экране радара — круги
  найденных вращений с номером (цвет — сила), в боковой панели — Vrot, диаметр, основание и

- **01.10.2026 — радар: отдельный экран доплеровского радара (кнопка «◉ Радар» в шапке).** PPI —
  отражаемость на выбранном угле наклона луча (14 углов NEXRAD, 0,5–19,5°); высота луча растёт с
  дальностью по модели «4/3 радиуса Земли» (0,5° на 100 км — 1,46 км), поэтому низкий наклон видит

  азимуты через 30°, ступенчатая палитра NWS 5–75 dBZ, под курсором — азимут, дальность, высота
  луча и dBZ; щелчок переносит радар. Отражаемость — рэлеевское рассеяние с распределениями
  микрофизики модели, как calc_dbz в WRF: 1 г/м³ дождя — 43 dBZ (Маршалл–Палмер), крупа ярче,
  тающий лёд — яркая полоса.
- **01.10.2026 — радар: доплеровская скорость (V), скорость относительно грозы (SRV) и составная
  отражаемость (CR).** V — проекция ветра на луч: (u·sin az + v·cos az)·cos(наклон) + (w − V_t)·sin(наклон),
  V_t — скорость падения осадков, взвешенная по отражаемости; видна только при эхе ≥ 5 dBZ; зелёное —
  к радару, красное — от радара. SRV вычитает движение грозы (Банкерс, правая ячейка) — так
  проявляется пара «к радару / от радара» мезоциклона, которую движение грозы маскирует. CR —
  сильнейшее эхо по всем 14 наклонам. Отражаемость и скорость падения считаются один раз в узлах
  модели и интерполируются вдоль лучей (составная в разы быстрее).

- **29.09.2026 — точный перенос по умолчанию; ограничители 100 / 120 м/с; термик без добавки
  пара.** WENO теперь основной перенос во всех сценариях (быстрый остался в переключателе).
  С ним восходящие потоки сильнее — модель берёт 70–80 % от √(2·CAPE), и при CAPE ~3 кДж/кг
  поток доходил до 60 м/с, в прежний ограничитель. Ограничитель — предохранитель, а не условие
  устойчивости (число Куранта при 100 м/с ~0,15), поэтому он поднят до |w| ≤ 100 и
  |u|, |v| ≤ 120 м/с: срабатывание теперь значит «расчёт пошёл вразнос», а не «сильная гроза».

  пар (+3 г/кг давали воздуху термика CAPE много больше, чем у среды), как в опыте WK.
- **29.09.2026 — точный перенос сохраняет воду сам, без поправки массы.** Проекция давления
  убирает дивергенцию на «двойственных» ячейках, а перенос считает потоки через грани ячеек
  вокруг узлов — это разные дивергенции, и поток массы через грани не был замкнут (поэтому
  WENO держал член q·div и поправку массы). Теперь потоки через грани проходят свою точную
  проекцию (MAC-проекция Белла–Колеллы–Глаза, спектральный решатель как у давления, общее
  преобразование Фурье — `src/core/spectral.ts`). Дождь в режиме WENO тоже переносится
  потоками, оседание — поток ρ·q_r·V_t через грани, вытекающее через землю идёт в осадки.
  Отрицательные значения, которые WENO оставляет, заполняются без изменения суммы. Итог:
  за 30 минут грозы вода меняется на 2·10⁻⁷ (округление float32), поправка массы в WENO
  больше не нужна. Основным перенос пока не стал: с ним сценарии упираются в 60 м/с.
