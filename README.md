# StormLab

Идеализированная облакоразрешающая модель глубокой конвекции, которая считается в браузере
в реальном времени, с 3D-визуализацией и диагностикой в духе оперативной синоптики.
Задаётся зондирование (профили температуры, влажности и ветра) и поверхность, дальше
модель интегрирует уравнения движения, термодинамики и тёплой микрофизики на сетке ~1 км.

**Статус.** Версия 1.x работает; идёт переход к 2.0, цель которого — чтобы числам модели
можно было доверять (план — [`roadmap.markdown`](roadmap.markdown)). Часть физики пока
упрощена или подогнана; всё известное перечислено в разделе
[«Известные ограничения»](#известные-ограничения) с замерами.

## Быстрый старт

Нужны [Node.js](https://nodejs.org/) 20+ и браузер с WebGL 2.

```bash
git clone https://github.com/Bandananor/MeteoLAB.git
cd MeteoLAB
npm install
npm run dev      # приложение: http://localhost:5173
npm test         # тесты расчётного ядра (Node, без браузера)
npm run test:slow  # калибровочный тест Weisman–Klemp (~15 мин)
npm run test:scenarios  # все 8 сценариев по 40 мин модели (~1,5 ч)
npm run build    # проверка типов и сборка в dist/
```

Медленные тесты удобнее гонять в облаке: workflow `.github/workflows/slow-tests.yml` (GitHub Actions) считает
быстрые тесты, Weisman–Klemp и каждый сценарий отдельной задачей параллельно, ~20 мин. Запускается сам при
изменении `src/core/` в `main` или вручную: вкладка Actions → Tests → Run workflow.

## Постановка модели

### Область и сетка

| | |
|---|---|
| Область | 48 × 36 × 18,9 км, периодическая по горизонтали; по выбору — большая, 96 × 72 км с тем же шагом (в ~4 раза медленнее). Область движется вместе с грозой (см. ниже) |
| Сетка | 40 × 32 × 50 узлов: Δx = 1,2 км, Δy = 1,125 км; по высоте растянутая — 100 м у земли, шаг растёт в геометрической прогрессии: 9 уровней ниже 1 км, ~340 м на 5 км, ~630 м у тропопаузы, ~970 м наверху |
| Границы по вертикали | земля и верх — непроницаемые стенки (w = 0); губка Рэлея выше max(z_тп + 2,5 км, 14 км) |
| Шаг по времени | Δt = 1 с |
| Размеры | параметры ядра (`createGrid`); в интерфейсе — «Стандарт» и «Большая» (`SimConfig.domain`) |
| Движение области | преобразование Галилея (`SimConfig.followStorm`, по умолчанию включено): модель считает в системе, движущейся со скоростью грозы — правой ячейки по Банкерсу при сдвиге 0–6 км от 15 м/с, иначе среднего ветра 0–6 км. Ветер модели — относительно области, фоновый — минус скорость области; трение у земли тянет к ветру над землёй; неоднородность поверхности и сумма осадков привязаны к земле, радар — тоже |

### Переменные и базовое состояние

Прогностические поля в узлах сетки: u, v, w; потенциальная температура θ; массовые доли
пара q_v, облачной воды q_c, дождя q_r; индикатор холодного купола (cold pool).

Базовое состояние горизонтально однородно и задаётся ползунками:
T(z) — кусочно-линейная с градиентами в слоях 0–3, 3–8 км и 8 км–тропопауза и инверсией
выше, плюс необязательный задерживающий слой: на заданной высоте воздух теплеет на заданные
K в слое 300 м, а над ним лишнее тепло сходит на нет за 2 км (крутой градиент приподнятого
перемешанного слоя, EML); относительная влажность — кусочно-линейная по узлам 0; 1,5; 5 км и тропопауза, плюс
необязательный влажный перемешанный слой: до заданной высоты массовая доля пара равна приземной
(как в хорошо перемешанном пограничном слое днём), но не выше насыщения;
ветер — скорость и направление в узлах 0, 3, 6 и 10 км с линейной интерполяцией.
Давление интегрируется гидростатически по этому профилю: dp/dz = −p·g/(R_d·T_v),
p₀ = 1013,25 гПа. Относительная влажность понимается как отношение массовых долей
(r = RH·r_s, соглашение ВМО).

### Динамика

- Неупругое (anelastic) приближение: ∇·(ρ₀(z)**u**) = 0, ρ₀ — плотность гидростатического
  базового состояния (падает примерно в 8 раз к 19 км).
- Плавучесть B = g·[(θ_v − θ_v0)/θ_v0 − q_c − q_r], θ_v = θ·(1 + 0,61·q_v): конденсат
  утяжеляет воздух своей массой.
- Сила Кориолиса на f-плоскости, действует на отклонение ветра от фонового
  (фоновый ветер считается геострофическим).
- Подсеточная турбулентность Смагоринского–Лилли: K = (C_s·Δ)²·√max(0, |S|² − N²/Pr), C_s = 0,18
  (ползунок «Субсеточная турбулентность» — множитель), Pr = 1/3; перемешиваются отклонения u, v, w,
  θ, q_v, q_c от фона во всех трёх направлениях (`src/core/turbulence.ts`).
- Трение у земли — балк-формула: dV/dt = −C_D(|V|V − |V₀|V₀)/(Δz/2) для нижнего узла,
  C_D = (κ/ln(z_ref/z₀))² по шероховатости поверхности (трава 3 см, вода 0,2 мм, город 1 м).
  Сопротивление фонового ветра считается уравновешенным крупномасштабным потоком, фон не дрейфует.
- Параметризованы: подъём воздуха на краю холодного купола и радиальный отток микропорыва.

### Численные методы

- **Перенос** (по умолчанию с 29.09.2026) — в форме потоков, WENO5 + RK3 (Wicker–Skamarock):
  WENO 5-го порядка для воды и индикатора холодного купола, линейная схема 5-го порядка для
  u, v, w, θ. Каждый узел — свой контрольный объём; потоки массы через грани проходят свою
  точную проекцию (MAC-проекция Белла–Колеллы–Глаза), поэтому схема сохраняет воду сама,
  без поправок. Оседание дождя — поток ρ₀·q_r·V_t через грани, вытекающее через землю — осадки.
  Отрицательные значения, которые WENO оставляет, заполняются без изменения суммы.
  Код: [`src/core/advection.ts`](src/core/advection.ts). Запасной вариант (переключатель
  «Перенос») — полулагранжев с трилинейной интерполяцией, вдвое быстрее, но размывает потоки.
- **Проекция давления** — точная и согласованная. Скорости хранятся в узлах, давление —
  в центрах «двойственных» ячеек между узлами. Дивергенция ячейки D — поток через её
  грани по восьми углам (именно её видит трилинейный перенос), градиент G = −M⁻¹Dᵀ
  (половинный вес узлов на стенках); условие — D(ρ₀**u**) = 0, так что D·ρ₀·G — согласованный
  лапласиан с весом плотности (поправка — градиент p′/ρ₀). Плотность зависит только от z, поэтому он
  диагонализуется двумерным ДПФ по x, y; для каждой волны решается трёхдиагональная
  система по z. Остаточная дивергенция после проекции ~10⁻¹¹ с⁻¹ (предел float32).
  Код: [`src/core/pressure.ts`](src/core/pressure.ts).
- **Фиксатор массы воды** (только для полулагранжева переноса). Он не консервативен
  (без поправки гроза создаёт ~7,5 % воды в час даже на строго бездивергентной скорости).
  После переноса массы q_v, q_c, q_r (вес ρ₀) восстанавливаются (для дождя — за вычетом
  выпавшего на землю), поправка распределяется пропорционально локальному изменению поля.
  В переносе WENO не используется.

### Микрофизика (тёплая, объёмная)

- Насыщающая коррекция за один шаг: Δq = (q − q_s)/(1 + L²·q_s/(c_p·R_v·T²)), два шага
  Ньютона; избыток пара конденсируется, облако в ненасыщенном воздухе испаряется до насыщения.
- Схема Кесслера (как в Klemp & Wilhelmson 1978 и CM1): автоконверсия 0,001·(q_c − 1 г/кг) с⁻¹,
  аккреция 2,2·q_c·q_r^0,875 с⁻¹.
- Скорость падения дождя V_t = 36,34·(0,001·ρ₀q_r)^0,1364·√(ρ₀(0)/ρ₀) м/с на каждом узле;
  дождь уходит в землю, сумма осадков копится по столбцам (мм).
- Испарение дождя по Klemp–Wilhelmson ∝ (1 − q/q_s)·C·(ρ₀q_r)^0,525, не дальше насыщения;
  охлаждение от него пишется и в θ, и в индикатор cold pool.
- **Лёд** (по умолчанию с 29.09.2026; переключатель «Микрофизика»;
  [`src/core/ice.ts`](src/core/ice.ts), [`src/core/graupel.ts`](src/core/graupel.ts)): облачный
  лёд, снег и крупа по Lin, Farley & Orville (1983)
  с насыщающей коррекцией для смеси воды и льда (Tao et al. 1989). Насыщение над льдом,
  доля льда в облаке линейно от 0 при 0 °C до 1 при −40 °C с теплотой плавления, дождь ниже
  −40 °C замерзает сразу; агрегация льда в снег, сбор снегом льда и облачных капель (обзернение),
  рост и сублимация снега, таяние в дождь, которое не охлаждает воздух ниже 0 °C; оседание снега
  (≈1 м/с) — поток через грани. Крупа (≈8 м/с): замерзание переохлаждённого дождя по Бигу,
  превращение обзернённого снега в крупу, сбор крупой капель, дождя, льда и снега, таяние.
  Вес льда, снега и крупы входит в плавучесть. Града как отдельного класса пока нет. Режим
  «Тёплый дождь» оставлен в переключателе.
  Снег на экране по умолчанию — визуализация частиц осадков по высоте уровня 0 °C.

### Поверхность и солнце

Инсоляция — «солнце в зените» × косинус зенитного угла (день равноденствия, учитывается
широта; восход 6:00, закат 18:00). Баланс энергии поверхности
`src/core/surface.ts`: поглощённое = длинноволновые потери (90 Вт/м²) + запас в почве/воде +
H + LE. Доля испарения — «мокрая» доля поверхности × доступность влаги (тип поверхности,
влажность почвы). H и LE целиком уходят в два нижних уровня (профиль exp(−z/300 м)):
Δθ = H/(ρc_pΠh), Δq = LE/(ρL_vh). Ночного выхолаживания нет.

### Диагностика

- Частица поднимается по давлению среды: сухая адиабата (сохранение θ) до LCL, псевдовлажная
  адиабата dT/dp выше, шаг 25 м. Совпадает с MetPy 1.7.1: CAPE ±1,1 %, CIN ±2 Дж/кг.
- Зондирование частицы от поверхности (в приложении: +0,5 K и вовлечение; для тестов есть
  «чистая» частица), CAPE, CIN, LCL, LFC, EL, точка росы, уровень 0 °C.
- Годограф 0–10 км и сдвиг ветра 0–6 км.
- Спиральность восходящего потока UH = ∫ w·ζ dz по слою 2–5 км (по столбцам). Пороги
  откалиброваны под эту сетку на реалистичных сценариях: «вращение» ≥ 200 м²/с²,
  «мезоциклон» ≥ 400 м²/с², в 1,5 раза сильнее самого сильного антициклонического вращения
  и держится ≥ 10 мин (в 3-км оперативных моделях обычно ~75). Второе условие отсекает пары
  вихрей разного знака, которые сильный поток при слабом сдвиге даёт с UH до ~380.
- Число восходящих ядер (связные по горизонтали столбцы, где на ~2–6,5 км есть w > 2 м/с с облаком)
  и классификация режима: одиночная ячейка, мультиячейка, наклонённая ячейка,
  суперячейка с мезоциклоном, преобладание оттока.
- **Ячейки** ([`cells.ts`](src/core/cells.ts)): ядро ячейки — связные (8 соседей) столбцы, где на 1,5–10 км
  есть w > 4 м/с в облаке. Ячейка продолжается там, где её ядро, сдвинутое на её собственное движение,
  перекрывает новое; при расщеплении номер остаётся у части с сильнейшим циклоническим вращением
  (правая ячейка), при слиянии — у суперячейки, затем у старшей. Номер даётся ядру, прожившему 2 мин
  (иначе обломки у края грозы, сливающиеся обратно, получают десятки номеров). Показатели ячейки —
  по её «области»: столбцы ближе 10 км к её центру и ближе к ней, чем к другим ячейкам. Стадии:
  кучевая (дождя у земли < 1 мм/ч), зрелая, распад (поток < 0,45 от максимума или нисходящий сильнее
  восходящего); развитие мезоциклона (UH ≥ 200 и в 1,5 раза больше антициклонического); суперячейка
  (мезоциклон 10 мин), окклюзия (холодный отток ≥ 2 K под низким вращением и UH < 0,7 максимума),
  новый мезоциклон после окклюзии, вращение ослабло, распад; левая суперячейка (антициклоническая).
  Новая стадия должна продержаться 1 мин.
- **Обнаружение мезоциклона на радаре** ([`mda.ts`](src/core/mda.ts)), по схеме алгоритма MDA (NSSL):
  на каждом из 14 наклонов — сдвиговые отрезки вдоль дальности (скорость растёт по часовой стрелке
  на ≥ 10 м/с, сдвиг ≥ 3·10⁻³ с⁻¹, длина ≤ 10 км); они объединяются в 2D-признаки (≥ 3 соседних
  строба), признаки — в вертикальные столбы (≥ 3 наклона, глубина ≥ 1,5 км). Vrot — половина
  перепада скорости; сила — по номограмме вращательной скорости (слабый ≥ 12,5, умеренный ≥ 18,
  сильный ≥ 23 м/с; ниже — «циркуляция»). Крюк: на 0,5° эхо ≥ 30 dBZ обвивает низкую циркуляцию
  на 180–330°, а вырез (< 20 dBZ) смотрит в сторону притока — вправо от движения грозы.

## Известные ограничения

Замеры — на тестах ядра (`npm test`); пункт плана указан для каждой строки.

| Ограничение | Что даёт сейчас | Пункт плана |
|---|---|---|
| Параметризованные cold pool и микропорыв, двойной учёт cold pool | фронт порывов не из динамики | ур. 2 |
| Горизонтальный шаг ~1,2 км | вовлечение, тонкие струи и вихри у земли не разрешены | ур. 3 (WebGPU, шаг ~500 м; вложенная сетка) |
| θ и поля хранятся в float32 | очень медленный нагрев (меньше ~10⁻⁴ K за шаг) округляется систематически; поэтому потоки от поверхности кладутся только в слой до 500 м | ур. 3 (радиация — хранить θ точнее или копить приращения) |
| Периодическая область | гроза больше не выходит за край (область движется с ней), но соседние ячейки по-прежнему «приходят» с другой стороны; большая область 96 × 72 км в ~4 раза медленнее | ур. 3 (WebGPU) |
| Града как отдельного класса нет (только крупа) | крупные градины и полосы градобития не моделируются | ур. 2 (град), ур. 3 (молнии) |
| Точный перенос WENO (по умолчанию) вдвое дороже прежнего (~70 мс на шаг) | на слабом компьютере расчёт медленнее реального времени при большом ускорении | ур. 3 (WebGPU) |
| При слабом сдвиге поток ~0,8–0,9·√(2·CAPE) со льдом (в природе ~0,5–0,6; при сильном сдвиге у нас ~0,6) | пульсирующие грозы сильнее реальных, до ~65–70 м/с; сценарии держат CAPE 1–3,3 кДж/кг | ур. 2 (растянутая сетка), ур. 3 (шаг ~500 м) |
| Широкий начальный термик (~8 км) | сухой средний слой почти не ослабляет поток | ур. 3 (инструменты воздействия: размер термика) |
| Нет ночного выхолаживания, солнце — день равноденствия | суточный ход только днём | ур. 3 (радиация) |
| Зондирование и индексы — по фоновому профилю | не меняются за время расчёта | ур. 2 (живое зондирование) |

## Проверка

`npm test` запускает ядро в Node (vitest). Известные ошибки помечены `it.fails`: такой тест
обязан падать, и когда исправление заработает, vitest сообщит об этом — пометку снимают.

- **Инварианты** ([`invariants.test.ts`](src/core/invariants.test.ts)): фон без триггера
  за 3 ч (θ, ветер, q_v); баланс воды в грозе за 1 ч с учётом выпавшего дождя; проекция
  убирает однородный w и не оставляет дивергенции после шага в грозе.
- **Сверка с MetPy 1.7.1** ([`sounding.test.ts`](src/core/sounding.test.ts)): CAPE, CIN,
  LCL, LFC, EL поверхностной частицы на трёх профилях; эталоны записаны в тест,
  пересчёт — [`tests/reference/metpy_parcel.py`](tests/reference/metpy_parcel.py).
- **Решатель давления** ([`pressure.test.ts`](src/core/pressure.test.ts)): случайное поле
  на шести сетках, включая чётные размеры с «шахматной» модой.

```ts
import { AtmosphereModel, createGrid } from './src/core'

const model = new AtmosphereModel(config, createGrid({ nx: 40, ny: 32, nz: 30, width: 48_000, depth: 36_000, height: 18_900 }))
for (let s = 0; s < 3600; s++) { model.step(1); model.time += 1 }
console.log(model.rotation.uh, model.diagnostics().updraft, model.precipitation)
```

Модель детерминирована при заданном `config.seed`. Скорость — около 17 мс на шаг
на сетке по умолчанию (Node 24, один поток), из них ~7 мс проекция.

## Как пользоваться

Камера: ЛКМ — вращение, ПКМ — сдвиг, колесо — масштаб. Двойной клик по земле — тёплый
влажный пузырь. Изменение профилей перезапускает опыт; кнопки «Сценарии» выставляют
готовую погоду. Вкладки над сценой показывают поля (вертикальная скорость, отклонение
температуры, влажность, завихренность, UH, cold pool) срезами и объёмом; «Потоки» —
частицы по ветру; «Снег и дождь» — частицы осадков. Щелчок по облаку (или по его номеру) выбирает
ячейку: показатели справа относятся к ней, «Вся область» возвращает максимумы по всей области.

Сценарии заданы в [`src/core/scenarios.ts`](src/core/scenarios.ts); в подсказке кнопки — их ML CAPE,
CIN, сдвиг и SRH. Поведение — 45 минут расчёта (29.09.2026; на 07.10.2026 потоки сильнее, см. журнал):

| Сценарий | Среда | Поведение |
|---|---|---|
| Летний день | ML CAPE 2,7 кДж/кг, слабый сдвиг | гроза до ~50 м/с, ливень ~90 мм/ч, отток; мезоциклона нет |
| Сухой воздух | 2 кДж/кг, середина 15 % | поток почти как при влажной середине, дождя на треть меньше |
| Сдвиг ветра | 3 кДж/кг, сдвиг 13 м/с | многоячейковая гроза |
| Микропорыв | «перевёрнутое V», база ~2,8 км | облако до ~24 м/с, порыв у земли ~19 м/с |
| Заряженное ружьё | ML CIN ~140 Дж/кг, без термика | 20 мин тишины, затем крышку пробивает во многих местах |
| HSLC | 1,3 кДж/кг, SRH 0–1 км 300, сдвиг 35 м/с | низкие вращающиеся ячейки ~25–30 мин (точный перенос) |
| Жаркий город | 1,9 кДж/кг, городская поверхность | гроза до ~45 м/с |
| Суперячейка WK | формулы Weisman–Klemp | мезоциклон больше часа, расщепление |

Медленный тест `npm run test:scenarios` (~30 мин) проверяет, что ни один сценарий не упирается
в ограничитель скорости и что мезоциклон появляется только там, где задуман.

  во времени: номер сохраняется, пока ячейка движется; при расщеплении он остаётся у правой
  (вращающейся) части, при слиянии — у суперячейки или старшей. В «Состоянии конвекции» — список

  ячейка слилась с другой, выбор переходит к той; если распалась — к области целиком. На
  «Суперячейке» (60 мин): кучевая с 7-й минуты, развитие мезоциклона на 16-й, зрелая суперячейка
  на 25-й, окклюзия на 35-й (холодный отток 2,5 K под низким вращением, UH 1500 → 220), распад на

- **02.10.2026 — радар: обнаружение мезоциклона (MDA) и крюка.** На экране радара — круги
  найденных вращений с номером (цвет — сила), в боковой панели — Vrot, диаметр, основание и
  вершина, число наклонов, азимут и дальность, возраст и, для сверки, UH модели рядом. На
  «Суперячейке» алгоритм находит мезоциклон в 0,6–1,7 км от максимума UH модели (Vrot 16–18 м/с,

  гроза у края области видна целиком.

- **01.10.2026 — радар: отдельный экран доплеровского радара (кнопка «◉ Радар» в шапке).** PPI —
  отражаемость на выбранном угле наклона луча (14 углов NEXRAD, 0,5–19,5°); высота луча растёт с
  дальностью по модели «4/3 радиуса Земли» (0,5° на 100 км — 1,46 км), поэтому низкий наклон видит
  дождь у земли, высокий — ядро грозы и наковальню. Тёмный экран, кольца дальности через 5 км,
  азимуты через 30°, ступенчатая палитра NWS 5–75 dBZ, под курсором — азимут, дальность, высота
  луча и dBZ; щелчок переносит радар. Отражаемость — рэлеевское рассеяние с распределениями
  микрофизики модели, как calc_dbz в WRF: 1 г/м³ дождя — 43 dBZ (Маршалл–Палмер), крупа ярче,
  тающий лёд — яркая полоса.
- **01.10.2026 — радар: доплеровская скорость (V), скорость относительно грозы (SRV) и составная
  отражаемость (CR).** V — проекция ветра на луч: (u·sin az + v·cos az)·cos(наклон) + (w − V_t)·sin(наклон),
  V_t — скорость падения осадков, взвешенная по отражаемости; видна только при эхе ≥ 5 dBZ; зелёное —
  к радару, красное — от радара. SRV вычитает движение грозы (Банкерс, правая ячейка) — так
  проявляется пара «к радару / от радара» мезоциклона, которую движение грозы маскирует. CR —
  сильнейшее эхо по всем 14 наклонам. Отражаемость и скорость падения считаются один раз в узлах
  модели и интерполируются вдоль лучей (составная в разы быстрее).

- **29.09.2026 — завышенные потоки: турбулентность в облаке; лёд по умолчанию.** Опыты на
  «Летнем дне» (доля от √(2·CAPE)): было 89 %; солнце и число термиков почти не влияют. Найдена
  ошибка: турбулентность гасила перемешивание по сухой устойчивости, а внутри облака, на влажной
  адиабате, воздух почти нейтрален — в восходящем потоке не было вовлечения. Теперь в облаке
  устойчивость считается по θe (82 %). Константа Смагоринского 0,21–0,25 (как в WRF для км-сеток)
  дала бы 60–75 %, но тогда в опыте WK не рождается левая ячейка — оставлена 0,18; остаток
  завышения — предел сетки ~1 км (вовлечение делают неразрешённые вихри), он в известных
  ограничениях. «Мощная гроза» чуть прохладнее (SB CAPE 3,3 кДж/кг вместо 3,5). Лёд (облачный
  лёд, снег, крупа) теперь основная микрофизика.
- **29.09.2026 — лёд, этап 2: крупа.** Схема Lin et al. (1983): замерзание переохлаждённого
  дождя по Бигу (быстрое ниже ~−15 °C), обзернённый снег превращается в крупу, крупа собирает
  капли, дождь, лёд и снег и тает в дождь; падает ~8 м/с. С ней дождь у земли в летней грозе
  вернулся: 52 мм/ч к 30-й минуте, 8,9 мм к 40-й, холодный купол ~7 K; крупы до 9 г/кг,
  наковальня до 15 км. Лёд пока за переключателем — по умолчанию станет после перепроверки
  всех сценариев со льдом (медленный тест ~45 мин).
- **29.09.2026 — HSLC: термик 2,5.** Без добавки пара в термике малой CAPE сценария не хватало,
  чтобы мезоциклон продержался 10 минут; с термиком 2,5 — UH 480–590 на 20–30-й минуте.
- **29.09.2026 — лёд, этап 1: облачный лёд и снег (переключатель «Микрофизика»).** Схема Lin
  et al. (1983) с насыщающей коррекцией для смеси воды и льда (Tao et al. 1989); все фазовые
  переходы — с точной теплотой (L_v, L_f, L_s), вода со льдом сохраняется (тесты). В летней
  грозе к 20-й минуте — наковальня из кристаллов до 14–15 км, лёд до 4,5 г/кг, снег до 8 г/кг.
  Пока экспериментально: без крупы и града обзернённые частицы остаются медленным снегом, и за
  40 минут на землю выпадает 1,8 мм вместо 12,5 — основной микрофизикой лёд станет с этапом 2.
- **29.09.2026 — точный перенос по умолчанию; ограничители 100 / 120 м/с; термик без добавки
  пара.** WENO теперь основной перенос во всех сценариях (быстрый остался в переключателе).
  С ним восходящие потоки сильнее — модель берёт 70–80 % от √(2·CAPE), и при CAPE ~3 кДж/кг
  поток доходил до 60 м/с, в прежний ограничитель. Ограничитель — предохранитель, а не условие
  устойчивости (число Куранта при 100 м/с ~0,15), поэтому он поднят до |w| ≤ 100 и
  |u|, |v| ≤ 120 м/с: срабатывание теперь значит «расчёт пошёл вразнос», а не «сильная гроза».
  Завышение потоков записано в известные ограничения. Стартовый термик больше не добавляет
  пар (+3 г/кг давали воздуху термика CAPE много больше, чем у среды), как в опыте WK.
- **29.09.2026 — точный перенос сохраняет воду сам, без поправки массы.** Проекция давления
  убирает дивергенцию на «двойственных» ячейках, а перенос считает потоки через грани ячеек
  вокруг узлов — это разные дивергенции, и поток массы через грани не был замкнут (поэтому
  WENO держал член q·div и поправку массы). Теперь потоки через грани проходят свою точную
  проекцию (MAC-проекция Белла–Колеллы–Глаза, спектральный решатель как у давления, общее
  преобразование Фурье — `src/core/spectral.ts`). Дождь в режиме WENO тоже переносится
  потоками, оседание — поток ρ·q_r·V_t через грани, вытекающее через землю идёт в осадки.
  Отрицательные значения, которые WENO оставляет, заполняются без изменения суммы. Итог:
  за 30 минут грозы вода меняется на 2·10⁻⁷ (округление float32), поправка массы в WENO
  больше не нужна. Основным перенос пока не стал: с ним сценарии упираются в 60 м/с.
- **29.09.2026 — реалистичные сценарии вместо экстремальных.** Все сценарии пересобраны:
  CAPE 1–3,5 кДж/кг вместо 5–10, влажный перемешанный слой, инверсия там, где она бывает.
  Новые: «Заряженное ружьё» (крышка держит 20 минут, потом прорыв) и HSLC (сильный сдвиг при
  малой CAPE). Сценарии со сдвигом считаются точным переносом. Сценарии вынесены в ядро
  (`src/core/scenarios.ts`), в подсказке кнопки — их CAPE, CIN, сдвиг и SRH. Пороги
  мезоциклона пересчитаны (400 м²/с² и перевес над антициклоническим вращением в 1,5 раза):
  при прежних 150 «мезоциклон» находился в любой сильной грозе. Медленный тест проверяет,
  что вращение появляется только в «Суперячейке», HSLC и «Суперячейке WK». Старые
  экстремальные сценарии убраны: они упирались в ограничитель, и их цифрам нельзя было верить.
- **29.09.2026 — влажный перемешанный слой: найдена причина, почему грозы в ползунковых
  профилях жили меньше 40 минут.** Относительная влажность, заданная линейно, означает, что
  пар быстро убывает с высотой: при 65 % у земли и 60 % на 1,5 км на высоте 1 км пара уже на
  треть меньше. Поток втягивал сухой воздух, дождь почти не выпадал, холодного купола не было —
  и гроза распадалась к 30–40-й минуте (опыты: один пузырь, без солнца, влажная середина —
  не помогали). В зондировании Weisman–Klemp пар постоянен до ~1,5 км. Новый ползунок
  «Влажный перемешанный слой» держит приземную долю пара до заданной высоты; с ним суперячейка
  на ползунках при той же CAPE, что у WK (~3 кДж/кг), живёт 45+ минут с мезоциклоном
  (UH ~1000–1400, антициклоническое вращение в 5–10 раз слабее). Сверено с MetPy.
- **29.09.2026 — задерживающий слой (инверсия) в профиле; CAPE и CIN по правилам MetPy.**
  Два новых ползунка в «Температурном профиле»: сила инверсии (0–6 K) и её высота. Это
  «крышка» над влажным пограничным слоем — без неё у ползункового профиля не бывает заметного
  CIN. Заодно CAPE считается как у MetPy и SHARPpy: от нижнего LFC до верхнего EL за вычетом
  отрицательных участков между ними, CIN — чистая площадь ниже LFC. Раньше при инверсии над
  первым тёплым слоем CAPE обрывалась на ней (81 Дж/кг вместо ~6000). Сверено с MetPy на двух
  новых профилях с крышкой.
- **29.09.2026 — сценарий «Суперячейка WK».** Классический опыт Weisman–Klemp в приложении:
  зондирование WK (CAPE ~2,3 кДж/кг), годограф «четверть окружности», один термик, точный
  перенос. К 30-й минуте — суперячейка с мезоциклоном и наковальней, рядом антициклоническая
  левая ячейка. Первый сценарий из будущего набора реалистичных сред.
- **29.09.2026 — турбулентность Смагоринского–Лилли** вместо горизонтального сглаживания θ и q:
  вихревая вязкость от деформации потока с поправкой на устойчивость, перемешивание ветра, тепла
  и влаги по всем трём направлениям. В обычном режиме грозы почти не изменились; с точным
  переносом умеренные среды больше не выходят за ограничители. Счётчик ограничителей показал,
  что «Мощная гроза» (CAPE ~9 кДж/кг) упирается в 60 м/с и с прежней схемой — сценарии
  ждут переработки на реалистичные среды.
- **29.09.2026 — перенос в форме потоков (WENO5 + RK3), пока за переключателем.**
  `model.transport = 'weno'`: WENO 5-го порядка для влаги и индикатора холодного купола,
  линейная противопоточная схема 5-го порядка для u, v, w, θ, трёхшаговый Рунге–Кутта.
  Узкое пятно после оборота по области сохраняет 0,91 пика (трилинейный перенос — 0,32).
  Классическая суперячейка Weisman–Klemp с ним живёт больше часа (~30 м/с) и расщепляется
  на циклоническую правую и антициклоническую левую ячейки — калибровочный тест проходит
  (`npm run test:slow`). По умолчанию пока прежний перенос: WENO втрое дороже (~100 мс на
  шаг, в браузере при ускорении 8× успевает), выбор — «Перенос» в группе «Расчёт».
- **29.09.2026 — низкое вращение и кнопка «Мезоциклон».** В панели UH 0–1 и 0–3 км —
  признак низкоуровневого мезоциклона; кольцо мезоциклона можно выключить. Кнопка «Сумма
  осадков» проверена на живой грозе.
- **29.09.2026 — приземный слой вместо «×0,94 за шаг».** Трение по балк-формуле с шероховатостью
  поверхности: порыв у земли затухает за часы, а не за 16 секунд, оттоки гроз растекаются
  по земле. Тест «фон не меняется» теперь включает и нижний уровень.
- **29.09.2026 — дождь снова доходит до земли; карта суммы осадков.** После перехода на
  схему Кесслера скорость падения бралась в точке прибытия, а под дождевым столбом она
  нулевая — дождь опускался только с нисходящими потоками (баланс воды при этом сходился,
  поэтому тесты молчали). Теперь узел берёт скорость падения дождя над ним; тест требует
  осадков на земле. Кнопка «Сумма осадков» рисует выпавший дождь на земле, интенсивность —
  поток ρ·q_r·V_t у земли в мм/ч (раньше q_r·12000 по максимуму во всём объёме).
- **29.09.2026 — индексы суперячейки:** движение по Банкерсу (точки RM и LM на годографе),
  SRH 0–1 и 0–3 км, SCP и STP в панели (`stormIndices`, `src/core/kinematics.ts`); совпадают
  с MetPy (движение ±0,05 м/с, SRH ±1 м²/с², SCP и STP ±3 %).
- **29.09.2026 — узлы ветра на 0,5 и 1 км.** Годограф в нижних 3 км больше не одна прямая:
  изгиб в нижнем километре (признак смерчеопасной среды, большая SRH 0–1 км) задаётся
  ползунками. У сценариев без этих узлов профиль прежний.
- **29.09.2026 — верх модели на 18,9 км** (30 уровней, шаг по высоте прежний), губка с 14 км:
  вершины сильных гроз и перебросы через тропопаузу больше не упираются в поглощающий слой.
  Шаг расчёта примерно на 25 % дольше.
- **29.09.2026 — стандартные индексы частицы:** MLCAPE/MLCIN (перемешанный слой 100 гПа),
  MUCAPE (самая неустойчивая частица в нижних 300 гПа) и DCAPE (энергия нисходящего потока)
  в панели и в ядре (`parcelIndices`); совпадают с MetPy 1.7.1 (DCAPE ±0,3 %, MLCAPE ±3 %).
  CAPE приложения (+0,5 K, вовлечение) остаётся отдельной величиной.
- **29.09.2026 — режимы отображения слоёв:** «срезы + объём сильных отклонений», «только
  срезы», «только объём» — всё поле с настраиваемыми порогом прозрачности и плотностью.
- **29.09.2026 — счётчик срабатываний ограничителей скорости** (|u|, |v| ≤ 85, |w| ≤ 60 м/с)
  в панели состояния: не ноль — модель вышла из рабочего диапазона.
- **29.09.2026 — каждый запуск уникален.** Ползунок «Seed» убран: старт, перезапуск и выбор
  сценария берут новый случайный сид. Он хранится в адресе страницы (`?seed=…`), так что
  понравившийся первый запуск можно повторить по ссылке.
- **29.09.2026 — расчёт в Web Worker.** Физика идёт в отдельном потоке, интерфейс и сцена
  больше не ждут шагов модели. Хвост невыполненных шагов ограничен 12 шагами: после
  тормозящих кадров модель не «догоняет» минутами.
- **29.09.2026 — неупругое (anelastic) приближение.** Проекция делает бездивергентным поток
  массы ρ₀**u**, а не скорость: поднимающийся воздух расширяется, как в реальной атмосфере.
  Решатель остался точным (ДПФ + прогонка, веса ρ₀ в коэффициентах), вода сохраняется
  в массовых единицах. Уровень 1 плана закрыт, кроме калибровочного теста WK.
- **29.09.2026 — баланс энергии поверхности.** Инсоляция через косинус зенитного угла
  (зависит от широты), H + LE + запас + длинноволновые потери = поглощённому. Нагрев у земли
  в полдень ~200 Вт/м² вместо ~430, испарение в ~8 раз сильнее (раньше соотношение Боуэна
  было искажено). Ползунок «Солнце в зените», по умолчанию 1000 Вт/м².
- **29.09.2026 — калибровочный тест Weisman–Klemp.** Идеализированные среды задаются
  формулами (`EnvironmentProfile`, `weismanKlemp()`). Классическая суперячейка WK на
  нашей сетке пока не расщепляется и гибнет к 40-й минуте — тест помечен как известное
  отставание и станет приёмочным для улучшения переноса (уровень 2).
- **29.09.2026 — «Суперячейка» перенастроена под новую физику.** Теплее и влажнее
  (31 °C, 78 %), сильнее ветер (8/16/24/30 м/с) при том же повороте 140° → 255°:
  одна ячейка с мезоциклоном с 24-й по ~55-ю минуту, UH до 550 м²/с², вращение
  преимущественно циклоническое.
- **29.09.2026 — честное испарение, ползунки-подгонки удалены.** Охлаждение при испарении
  дождя — ровно L/c_p на испарённую массу. Ползунки «Вовлечение сухого воздуха»,
  «Эффективность осадков», «Испарение осадков», «Сила cold pool» удалены: микрофизика только

  сценариев — уровень 2).
- **28.09.2026 — схема Кесслера.** Автоконверсия в 35 раз медленнее (как у Кесслера),
  добавлена аккреция, испарение дождя по Klemp–Wilhelmson, скорость падения зависит от
  количества дождя и плотности воздуха. Дождь начинается позже, холодный купол слабее,
