# Хроника StormLab: как песочница с облаками стала моделью грозы

*Вся история репозитория `MeteoLAB` — коммит за коммитом, с пояснениями, цифрами и байками.*

---

## Пролог: что вообще происходит

StormLab — это трёхмерный симулятор атмосферной конвекции прямо в браузере: TypeScript, Three.js, сетка в несколько десятков километров, на которой из тёплого пузыря воздуха вырастает кучевое облако, потом гроза, а при удачном ветре — суперячейка с вращающимся восходящим потоком (мезоциклоном).

История репозитория умещается в **91 коммит за 11 дней** (27 сентября — 7 октября 2026). Но это не 11 дней равномерной работы, а скорее извержение: за первые трое суток сделано **75 коммитов**, причём **42 из них — за один день, 29 сентября**.

Если смотреть на историю целиком, у неё отчётливый сюжет:

1. **Красивая игрушка** (вечер 27.09): облака с raymarching, тени, солнце, пресеты — всё выглядит как настоящее.
2. **Час расплаты** (28.09): к модели пишут тесты — и выясняется, что она создаёт воду из ничего, давление решается «наполовину», а у пузыря вместо физики — подгоночные коэффициенты.
3. **Честная физика** (28–29.09): всё переписывается по учебникам и статьям, сверяется с MetPy и с классическим тестом Вайсмана–Клемпа.
4. **Лёд, радар и слежение за штормом** (29.09–03.10): модель обрастает ледяной микрофизикой, растянутой сеткой, доплеровским радаром и детектором мезоциклонов, как у метеослужбы США.
5. **Облачные тесты и чистка** (06–07.10): CI в GitHub Actions — и первый же прогон в облаке приносит неудобную правду, с которой начинается следующая глава.

### `df45d6a` · 20:11 — Initial commit: StormLab 3D atmospheric convection simulator

С чего всё началось. Сразу заявлен серьёзный набор: полу-лагранжева адвекция, проекция давления для несжимаемой жидкости, сила Кориолиса, балковая микрофизика, холодный бассейн и фронт порывов, а в диагностике — теория частицы: CAPE, CIN, LCL, LFC, EL.

**Что это значит.** Атмосфера разбита на 3D-сетку. На каждом шаге ветер «переносит» температуру, влагу и сам себя (адвекция), потом поле скоростей поправляют, чтобы воздух не сжимался и не исчезал (проекция давления). CAPE — это «запас топлива» для грозы: сколько энергии получит пузырь воздуха, если его поднять.

**Интересно:**
- Весь физический движок — файл `simulator3d.ts` на **111 строк**. Для сравнения: `package-lock.json` в том же коммите — 977 строк.
- Это **единственный коммит** в истории, соавтор которого — Claude Sonnet 5. Начиная со второго коммита (через 13 минут) и до конца — Claude Opus 5.5.
- В сообщении упомянут удалённый «неиспользуемый 2D-прототип». То есть у проекта есть доисторическая эпоха, которая в репозиторий не попала.

### `cad251d` · 19:54 — Replace the pressure projection with an exact, consistent solver

Ответ на главный баг. Давление переезжает в центры «двойственных» ячеек между узлами скорости. Дивергенция ячейки — поток через её грани, собранный с 8 углов (именно на это реагирует трилинейный перенос), а градиент — её точный сопряжённый оператор, так что D·G согласованы. Решение точное, без итераций: 2D-преобразование Фурье по горизонтали и одна трёхдиагональная система на каждое волновое число. Земля и верх — жёсткие стенки.

**Эффект в цифрах:**
- дивергенция после проекции: 10⁻³ → **10⁻¹¹ с⁻¹** (восемь порядков);
- дрейф спокойной атмосферы за 3 ч: 0,28 K → **0,004 K**;
- рождение воды в грозе: +27 % → +7,5 %/ч;
- шаг: 23 → 17 мс (точный решатель ещё и быстрее итеративного).

**Цена честности:** «грозы стали слабее и честнее; пресет „Суперячейка“ больше не развивается». Суперячейка, рождённая вчера вечером, умерла от правильной физики.

### `6ec16d4` · 20:36 — Hydrostatic base state and a parcel that follows pressure

- Фоновое давление интегрируется из уравнения статики по собственной виртуальной температуре среды. Старое `p0·exp(−z/8 км)` ошибалось **на 20 % на 15 км**.
- Частица поднимается по давлению среды (сухая адиабата, псевдоадиабата методом средней точки, шаг 25 м). Старая схема по высотам неявно полагала T_частицы = T_среды и при сильной неустойчивости оставляла частицу **на 6,5 K теплее** на 12 км.

**Байка о неправильном эталоне:** оказалось, что *эталон MetPy тоже был неверен*. MetPy 1.7 сам вносит виртуальную поправку, а ему передали уже виртуальные температуры (CIN 59 вместо 124 Дж/кг). Вдобавок влажность считалась через давление пара, а модель — через отношение смеси по WMO. После пересчёта CAPE совпадает с точностью 1,1 %, CIN — 2 Дж/кг. **Все 21 тест зелёные.** Мораль: тест показывает расхождение, но ошибиться при этом может и сам эталон.

### Словарик для тех, кто дочитал

| Термин | По-простому |
|---|---|
| **CAPE / CIN** | Энергия, которую получит поднимающийся пузырь / энергия, которую надо потратить, чтобы его до этого поднять («крышка») |
| **LCL / LFC / EL** | Уровень конденсации (основание облака) / уровень свободной конвекции (отсюда пузырь летит сам) / уровень равновесия (примерно верх облака) |
| **Суперячейка** | Гроза с долгоживущим вращающимся восходящим потоком — мезоциклоном |
| **Правый / левый мувер** | Две половинки расщепившейся суперячейки; в северном полушарии обычно доминирует правая, циклоническая |
| **UH** | Спиральность восходящего потока: насколько поток одновременно поднимается и вращается |
| **SRH** | Спиральность относительно шторма: насколько окружающий ветер «закручивает» втекающий воздух |
| **SCP / STP** | Составные индексы суперячейки и значимого торнадо, как у Storm Prediction Center |
| **HSLC** | High Shear, Low CAPE — сильный сдвиг ветра при слабой неустойчивости |
| **Полу-лагранжев перенос** | Для каждой точки смотрим, откуда прилетел воздух, и берём значение оттуда; быстро, но размазывает |
| **WENO5** | Схема переноса 5-го порядка, которая остаётся резкой на фронтах и не даёт ложных колебаний |
| **Проекция давления** | Шаг, который подправляет ветер так, чтобы воздух не сжимался и не появлялся из ниоткуда |
| **Неупругое приближение** | То же, но с учётом того, что наверху воздух реже |
| **dBZ** | Логарифмическая мера отражённого радарного сигнала; 40+ — сильный дождь, 60+ — град |
| **PPI / VCP 12** | Круговой обзор радара на одном угле / стандартная стратегия NEXRAD из 14 углов |
| **MDA** | Алгоритм обнаружения мезоциклона по доплеровским данным |
| **Крюкообразное эхо** | Загиб на радарной картинке у основания суперячейки — классический признак возможного торнадо |
